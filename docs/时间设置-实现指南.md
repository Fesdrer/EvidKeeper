# 业力衰减时间设置 — 编程实现指南

> 功能位置：设置页面 → 业力衰减 → 扣除时间

## 一、功能流程总览

```
点击时间盒子 → TimePickerDialog 弹出 → 滑动选择时/分 → 点"确定" → onDecayTimeChange(h, m)
    → ViewModel.updateDecayTime(h, m) → 只改内存 draft
    → 点"保存设置" → repository.updateAllSettings(draft) → Room 落库
```

代码分布在 3 个文件：

| 层 | 文件 | 职责 |
|---|---|---|
| UI | [SettingsScreen.kt](../app/src/main/java/com/example/karma/ui/settings/SettingsScreen.kt) | 入口盒子、对话框、滑动选择器 |
| ViewModel | [SettingsViewModel.kt](../app/src/main/java/com/example/karma/ui/settings/SettingsViewModel.kt) | 编辑内存 draft |
| 数据 | [KarmaSettingsEntity.kt](../app/src/main/java/com/example/karma/data/local/entity/KarmaSettingsEntity.kt) | `decayHour` / `decayMinute` 字段（默认 23:00） |

## 二、第一步：可点击的入口盒子

位于 [SettingsScreen.kt:581-607](../app/src/main/java/com/example/karma/ui/settings/SettingsScreen.kt#L581-L607) 的 `DecaySettingsCard` 内：

```kotlin
// ① 用 remember 控制对话框是否弹出
var showTimePicker by remember { mutableStateOf(false) }

// ② 金色描边的盒子，点击打开对话框，显示当前值
Box(
    modifier = Modifier
        .fillMaxWidth()
        .border(1.dp, Gold.copy(alpha = 0.25f), RoundedCornerShape(8.dp))
        .clip(RoundedCornerShape(8.dp))
        .clickable { showTimePicker = true }   // 点击 → 弹窗标志
        .padding(12.dp),
    contentAlignment = Alignment.Center,
) {
    Text(text = String.format("%02d:%02d", decayHour, decayMinute), ...)  // 显示 "23:00"
}

// ③ 条件组合：标志为 true 时才组合对话框
if (showTimePicker) {
    TimePickerDialog(
        initialHour = decayHour,
        initialMinute = decayMinute,
        onConfirm = { hour, minute -> onDecayTimeChange(hour, minute) },
        onDismiss = { showTimePicker = false },
    )
}
```

要点：`decayHour`/`decayMinute` 是**外部传入的参数**（来自 draft），对话框关闭后盒子会因参数变化自动重绘出新时间。

## 三、第二步：TimePickerDialog 对话框

位于 [SettingsScreen.kt:1560-1614](../app/src/main/java/com/example/karma/ui/settings/SettingsScreen.kt#L1560-L1614)：

```kotlin
var selectedHour by remember { mutableStateOf(initialHour) }
var selectedMinute by remember { mutableStateOf(initialMinute) }

AlertDialog(
    title = { Text("选择扣除时间", ...) },
    text = {
        Row(horizontalArrangement = Arrangement.Center, ...) {
            ScrollPicker(range = 0..23, selected = selectedHour, ...)   // 时，占一半宽
            Text(":", fontSize = 24.sp, ...)
            ScrollPicker(range = 0..59, selected = selectedMinute, ...) // 分，占一半宽
        }
    },
    confirmButton = {
        Button(onClick = {
            onConfirm(selectedHour, selectedMinute)   // ① 回传选好的时间
            onDismiss()                               // ② 关闭对话框
        }, ...) { Text("确定") }
    },
    dismissButton = { TextButton(onClick = onDismiss) { Text("取消", ...) } },
    containerColor = Color(0xFF1A1A1A),
)
```

关键点：**局部状态 vs 全局状态** —— 用户滑动时只改 `selectedHour`/`selectedMinute` 局部变量，**不碰 draft**；只有点「确定」才通过 `onConfirm` 一次性回传。取消则直接丢弃，不影响任何数据。

## 四、第三步（核心）：ScrollPicker 滑动选择器

位于 [SettingsScreen.kt:1620-1729](../app/src/main/java/com/example/karma/ui/settings/SettingsScreen.kt#L1620-L1729)。这是整个功能的技术核心，由 5 个机制组成：

### 机制 1：循环列表（3 份数据实现无限滑动）

```kotlin
val baseItems = range.toList()                  // [0..23] 或 [0..59]
val baseSize = baseItems.size
// 重复 3 份 → 往哪滑都滑不到尽头
val items = remember(range) { buildList { repeat(3) { addAll(range.toList()) } } }
val itemHeight = 44.dp
val visibleItems = 5                            // 视口高度 = 44 × 5 = 220.dp
```

### 机制 2：初始定位居中

```kotlin
// 定位到「第 2 份」副本里选中项的位置，再减去 visibleItems/2
// 因为 LazyColumn 的 initialFirstVisibleItemIndex 指向视口顶部项，
// 减 2 后选中项正好落在视口中间（第 3 位）
val startIndex = baseSize + baseItems.indexOf(selected).coerceAtLeast(0) - visibleItems / 2
val listState = rememberLazyListState(initialFirstVisibleItemIndex = startIndex.coerceAtLeast(0))
```

### 机制 3：实时检测"哪一项在正中间"

```kotlin
val centerItemIndex by remember {
    derivedStateOf {
        val layoutInfo = listState.layoutInfo
        val viewportCenter = layoutInfo.viewportEndOffset / 2     // 视口中心线
        layoutInfo.visibleItemsInfo.minByOrNull { info ->
            abs((info.offset + info.size / 2) - viewportCenter)   // 找离中心线最近的一项
        }?.index?.coerceIn(0, totalSize - 1) ?: 0
    }
}

// 选中值通过取模归一化：第 25 项 → 25 % 24 = 1，永远落在 base 范围内
LaunchedEffect(centerItemIndex) {
    onSelected(baseItems[centerItemIndex % baseSize])
}
```

这个 `derivedStateOf` 是「当前选中值」的唯一数据源，滑动过程中值会实时变化。

### 机制 4：松手吸附（自动滚到居中位置）

```kotlin
LaunchedEffect(Unit) {
    // 必须用 snapshotFlow 监听滚动状态，不能用 LaunchedEffect(isScrollInProgress) 作 key
    // （后者会在 animateScrollToItem 触发状态变化时重启协程，动画被取消）
    snapshotFlow { listState.isScrollInProgress }
        .collect { scrolling ->
            if (!scrolling) {
                delay(60)   // 等惯性滚动完全结束
                val closest = ...  // 找离中心最近的一项
                val diff = closest.offset + closest.size / 2f - viewportCenter
                if (abs(diff) > 4f) {
                    // animateScrollToItem 会把目标放到视口顶部，
                    // 所以要减去 visibleItems/2，让目标落到第 3 位 = 正中间
                    val snapFirst = (closest.index - visibleItems / 2).coerceIn(0, totalSize - 1)
                    listState.animateScrollToItem(snapFirst)
                }
            }
        }
}
```

### 机制 5：视觉呈现（高亮条 + 中心放大）

```kotlin
Box(/* 容器 = 220.dp 高，裁剪圆角 */) {
    // ① 金色高亮条：永远画在容器正中间（Compose Box 默认居中）
    Box(
        modifier = Modifier
            .fillMaxWidth().height(itemHeight)
            .background(Gold.copy(alpha = 0.12f))
            .border(1.dp, Gold.copy(alpha = 0.25f), ...),
    )

    // ② LazyColumn 列表浮在高亮条之上
    LazyColumn(state = listState) {
        itemsIndexed(items) { index, value ->
            val isCenter = index == centerItemIndex
            Box(/* 每项 44.dp 高，可点击 */) {
                Text(
                    text = String.format("%02d", value),
                    fontSize = if (isCenter) 22.sp else 14.sp,   // 中心项放大
                    fontWeight = if (isCenter) FontWeight.Bold else FontWeight.Normal,
                    color = if (isCenter) Color.White else TextMuted,
                )
            }
        }
    }
}
```

**层级关系（z-order）**：底部容器 → 高亮条（居中）→ LazyColumn 列表（覆盖其上）。高亮条不需要定位代码，因为 `Box(contentAlignment = Center)` 天然把它放正中间，滑动时列表在它下面移动，视觉上就像"高亮条选中了中间那一项"。

## 五、第四步：ViewModel 更新

[SettingsViewModel.kt:162-164](../app/src/main/java/com/example/karma/ui/settings/SettingsViewModel.kt#L162-L164)：

```kotlin
fun updateDecayTime(hour: Int, minute: Int) {
    setDraft(_draft.value.copy(decayHour = hour, decayMinute = minute))
}
```

只改内存里的 draft 副本，**不写数据库**。`setDraft` 还会置 `_userEdited = true`，防止异步初始加载覆盖用户编辑。

## 六、第五步：保存落库

页面底部「保存设置」按钮 → [SettingsViewModel.kt:255-264](../app/src/main/java/com/example/karma/ui/settings/SettingsViewModel.kt#L255-L264)：

```kotlin
fun save() {
    viewModelScope.launch {
        repository.updateAllSettings(_draft.value)   // 整个 draft 写入 Room

    }
}
```

## 七、复用到其他场景的实现步骤清单

如果想再做一个类似的滑动选择器（比如选等级、选数量）：

1. **数据**：在实体加字段（如 `val myValue: Int = 0`）+ ViewModel 加 `updateMyValue(v)`；
2. **入口**：复制 `DecaySettingsCard` 里的「盒子 + `showXxx` 标志 + 条件组合」三件套；
3. **对话框**：复制 `TimePickerDialog`，把两个 `ScrollPicker` 换成你需要的数量（单个用 `Modifier.fillMaxWidth()`）；
4. **ScrollPicker 本身不用改**：它只依赖 `range` 和 `selected` 两个参数，天然通用；
5. 别忘了 `onConfirm` 里调用新加的 ViewModel 方法，并保持「局部状态滑、确定才回传」的模式。

## 八、已知陷阱

**最容易踩的坑**（代码注释里已写明）：吸附动画必须用 `snapshotFlow` 监听 `isScrollInProgress`，如果用 `LaunchedEffect(isScrollInProgress)` 当 key，动画进行中会不断重启协程导致滚动卡死。
