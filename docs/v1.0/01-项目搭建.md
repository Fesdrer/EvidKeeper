# 步骤 1：项目搭建

> 目标：在 Android Studio 中创建 EvidKeeper 项目并跑通一个空应用。前置：无（从零开始）。

## 一、任务清单

1. **创建项目**：Android Studio → New Project → **Empty Activity（Compose）**。
   - 项目名 `EvidKeeper`，包名 `com.evidkeeper`，Min SDK 26，语言 Kotlin。
   - AGP / Gradle / Kotlin / Compose 版本全部用 Android Studio 默认推荐，不要手改。
2. **依赖**（app/build.gradle.kts）：
   - Compose BOM、`androidx.activity:activity-compose`、`androidx.compose.material3:material3`
   - `androidx.navigation:navigation-compose`
   - `androidx.lifecycle:lifecycle-viewmodel-compose`（+ `lifecycle-runtime-compose` 用于 collectAsStateWithLifecycle）
   - `com.squareup.okhttp3:okhttp`
   - `org.jetbrains.kotlinx:kotlinx-serialization-json`（并在 plugins 加 `kotlin("plugin.serialization")`）
   - `androidx.security:security-crypto`（EncryptedSharedPreferences 存 API Key）
   - `io.coil-kt:coil-compose`（图片缩略图）
   - 全部用最新稳定版即可。
3. **AndroidManifest.xml**：
   - 加 `<uses-permission android:name="android.permission.INTERNET" />`（AI 功能用）。
   - 声明 FileProvider（系统查看器打开文件用）：
     ```xml
     <provider
         android:name="androidx.core.content.FileProvider"
         android:authorities="com.evidkeeper.fileprovider"
         android:exported="false"
         android:grantUriPermissions="true">
         <meta-data
             android:name="android.support.FILE_PROVIDER_PATHS"
             android:resource="@xml/file_paths" />
     </provider>
     ```
4. **res/xml/file_paths.xml**（新建）：
   ```xml
   <?xml version="1.0" encoding="utf-8"?>
   <paths>
       <external-path name="external" path="." />
       <cache-path name="cache" path="." />
   </paths>
   ```
5. **目录骨架**：在 `app/src/main/java/com/evidkeeper/` 下建空目录（见 00 总览第四节），暂时只需 `ui/main/`、`data/` 存在即可，其余目录随步骤创建。
6. **MainActivity**：暂时放一个最简单的 Compose 屏幕（一个居中 Text "EvidKeeper"），确认能跑；后续步骤 03 会替换为主页面。
7. **App 名称**：`values/strings.xml` 中 `app_name` 改为 "EvidKeeper"。

## 二、验收清单

- [ ] 真机或模拟器运行，应用正常启动，显示 "EvidKeeper" 文本，无崩溃
- [ ] 编译无错误、无红色警告
- [ ] 所有依赖下载成功

> 说明：本步骤不实现任何业务功能。
