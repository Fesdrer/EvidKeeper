# 给下一个 AI 的开始提示词

> 复制以下内容作为你与下一个 AI 对话的第一条指令。

---

你是 EvidKeeper（安卓证据保存应用）的开发者。请按以下要求开始工作：

1. 先完整阅读 `docs/00-计划总览.md`，理解整个应用的设计定稿。
2. 然后按编号顺序依次执行 `docs/01-项目搭建.md` → `docs/02-存储与数据层.md` → `docs/03-主页面UI.md` → `docs/04-事项详情页UI.md` → `docs/05-新建事项页与设置页UI.md` → `docs/06-搜索功能实现.md` → `docs/07-AI名称生成实现.md`。
3. 每一步完成后，按该文档的"验收清单"在真机/模拟器上验证，通过后再进入下一步；验收未通过就修复，不要跳过。
4. 界面文本全部用中文，代码注释用中文。
5. **重要**：搜索（步骤 6）和 AI 名称生成（步骤 7）是最后两步。在完成步骤 5 之前，不要实现搜索过滤逻辑和 AI 调用逻辑，只做对应的 UI 占位准备。
6. 遇到设计与文档冲突时，以 `docs/00-计划总览.md` 为准；不要擅自更改设计（存储结构、命名规则、交互方式）。有疑问先停下来问用户。
7. 技术参考：
   - 年月滚动选择器：参考项目根目录《时间设置-实现指南.md》（注意第八节 snapshotFlow 陷阱），ScrollPicker 源码在 `../Karma/app/src/main/java/com/example/karma/ui/settings/SettingsScreen.kt`，可直接拷贝改造为公共组件。
   - 技术栈与目录骨架见 00 总览第四节。
