# 步骤 4：事项详情页 UI

> 目标：详情页完整 UI 与交互（文件网格、星标切换、改名、改时间、长按文件、添加文件、系统查看器）。**本步不涉及 AI。**
> 前置：步骤 2、3 完成。

## 一、界面布局

```
┌──────────────────────────────────────────┐
│ ←        事项名称         ★ 2026-08  │   ← 顶部栏
├──────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐             │
│ │缩略图 │ │ 图标 │ │ 图标 │             │   ← 大图标网格（3列）
│ │截图.jpg│ │回执.pdf│ │说明.txt│           │
│ └──────┘ └──────┘ └──────┘             │
│ ...                                     │
│                    (＋)                 │   ← 底部居中加号
└──────────────────────────────────────────┘
```

- 顶部栏：返回箭头（左）→ 事项名称（居中，点击改名）→ 星标（黄色=重要/灰色=普通，**点击切换**）→ 时间（`2026-08`，点击改年月）。
- 文件网格：`LazyVerticalGrid`，3 列；每格：上方缩略图/图标 + 下方文件名（单行省略）。
  - 图片文件 → Coil 加载缩略图（`rememberAsyncImagePainter`，从 ContentResolver 读 Uri）
  - pdf → PDF 图标；txt → 文本图标；其他 → 通用文件图标（可用 Material Icons 或简单绘制的图标占位）
- 底部：`＋` 按钮居中显示（固定在底部或列表最后一项，二选一，建议固定底部）。

## 二、交互

1. **返回箭头** → 返回主页面（主页面 ON_RESUME 自动刷新，改名/星标等改动会反映到列表）。
2. **点击星标** → 切换 important 并调 `StorageManager.toggleImportant` 写 meta；图标即时变黄/变灰。
3. **点击事项名称** → 改名对话框（同步骤 3 的校验规则：非法字符提示、撞名提示）。
4. **点击时间** → 弹出**年月选择器对话框**（默认当前值）。
   - 年月选择器 = 两个 ScrollPicker（年、月）并排，参考根目录《时间设置-实现指南.md》：
     - 年范围 `2000..2099`，月范围 `1..12`
     - 建议抽取成公共组件 `ui/components/YearMonthPickerDialog.kt`（本页和新建页共用）
     - **注意指南第八节陷阱**：吸附动画必须用 `snapshotFlow { listState.isScrollInProgress }`，不能用 `LaunchedEffect(isScrollInProgress)` 当 key
     - ScrollPicker 源码参考：`../Karma/app/src/main/java/com/example/karma/ui/settings/SettingsScreen.kt`（可直接拷贝改造）
   - 确定 → `StorageManager.changeTime` 写 meta；取消 → 丢弃。
5. **点击文件** → 系统查看器打开：
   - 用 FileProvider：`FileProvider.getUriForFile(context, "com.evidkeeper.fileprovider", 临时文件)` + `ACTION_VIEW` Intent + `FLAG_GRANT_READ_URI_PERMISSION`
   - 注意：SAF 的 DocumentFile 不能直接 `getUriForFile`，需要把文件内容复制到 `cacheDir` 临时文件再分享（系统查看器只认 `file://` 或内容型 Uri；**对系统查看器，直接传原 document uri（`content://`）也可能可行**——优先尝试直接把 document uri 传给 ACTION_VIEW，若打不开再回退临时文件方案）
   - `startActivity` 捕获 `ActivityNotFoundException` → Toast「没有应用可以打开此文件」
6. **长按文件** → 弹出菜单：
   - **改名**：对话框输入新主名（**不显示扩展名**，保存时自动补回原扩展名，如 `截图.jpg` 只编辑 `截图`）；改名后不能变成 `.meta.json` 的主名 `meta`（StorageManager.renameFile 处理，UI 传新主名即可）
   - **删除**：确认对话框（"删除文件「xxx」？文件将移入回收站"）→ `StorageManager.deleteFile` → 刷新网格
7. **`＋` 按钮** → `ACTION_OPEN_DOCUMENT`（`type = "*/*"`，单文件模式）→ 选中的文件经 `StorageManager.addFile` 移入事项文件夹（重名自动 `(1)`；若返回"未删原件"标记 → Toast「已复制，但无法删除原文件，请手动清理」）→ 刷新网格。

## 三、代码结构

- `ui/detail/DetailViewModel.kt`：
  - `val item: StateFlow<Item?>`（按传入 id 扫描加载）
  - `fun rename(...)`、`fun toggleImportant()`、`fun changeTime(y, m)`、`fun deleteFile(f)`、`fun renameFile(f, newName)`、`fun addFile(uri)` —— 全部调 StorageManager 后刷新
- `ui/detail/DetailScreen.kt`：布局 + 各对话框；接收导航参数（事项 id）。
- `ui/components/YearMonthPickerDialog.kt`：公共年月选择器。
