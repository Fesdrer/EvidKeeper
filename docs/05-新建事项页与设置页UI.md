# 步骤 5：新建事项页 + 设置页 UI

> 目标：新建事项页和设置页完整 UI 与本地逻辑。**「AI 生成」按钮本步只做占位（始终禁用态），AI 逻辑留到步骤 7**。
> 前置：步骤 2~4 完成。

## 一、新建事项页（`ui/create/`，主页面 `+` 进入）

```
┌──────────────────────────────────────┐
│  （添加文件按钮）                       │
│  名称：（新事项名称输入框）   [AI生成]   │
│  时间：（2026-08 显示框）              │
│             [创建]                     │
└──────────────────────────────────────┘
```

### 布局与交互

1. **「添加文件」按钮**（页面顶部）：
   - 点击 → `ACTION_OPEN_DOCUMENT`（`type = "*/*"`，单选）→ 选一个文件；
   - 选中后按钮下方显示文件名预览（如 `截图.jpg`）；**可再次点击更换**；
   - **允许不选文件**（事项可以先没有文件，之后在详情页补）。
2. **名称输入框**：普通 TextField。
3. **「AI 生成」按钮**（名称输入框右侧）：
   - **本步占位**：按钮保持禁用灰色，点击无反应或提示"AI 功能将在后续版本启用"——实现步骤 7 再接通；
   - 按钮 UI 上最好预留「生成中…」转圈态（步骤 7 用）。
4. **时间显示框**：显示 `2026-08`，默认当前年-月；点击 → 复用步骤 4 的 `YearMonthPickerDialog`。
5. **「创建」按钮**（底部）：
   - 校验名称**非空**且**不含非法字符**（`\ / : * ? " < > |`），违反 → 提示修改；
   - `StorageManager.createItem(name, year, month)` → 若选了文件则 `StorageManager.addFile(item, uri)`（重名自动 `(1)`；"未删原件"时 Toast 提示）；
   - 完成后导航回主页面（自动刷新），可 Toast「已创建事项」。

### ViewModel

- `ui/create/CreateViewModel.kt`：`name: StateFlow<String>`、`year/month: StateFlow<Int>`、`selectedFileUri: StateFlow<Uri?>`、`fun create()`；创建成功返回结果给 UI 导航。

## 二、设置页（`ui/settings/`，主页面齿轮进入）

```
┌──────────────────────────────────────┐
│ ←  设置                               │
│  存储文件夹：（当前目录或"未设置"）      │
│  API Key：  （******** 输入框）         │
│  AI模型：   （glm-4.6v-flash ▾）       │
│            [保存]                     │
└──────────────────────────────────────┘
```

### 布局与交互

1. **返回按钮**（左上）→ 返回主页面。
2. **存储文件夹行**：
   - 显示当前目录 Uri 字符串（未设置时显示"未设置"）；
   - 点击 → `ACTION_OPEN_DOCUMENT_TREE` → `takePersistableUriPermission()`（`FLAG_GRANT_READ_URI_PERMISSION | FLAG_GRANT_WRITE_URI_PERMISSION`）→ 存入 SettingsStore；
   - 重新打开应用后授权仍在（持久授权）。
3. **API Key 输入框**：密码样式（掩码） + 可见性切换图标；内容存 SettingsStore（EncryptedSharedPreferences）。
4. **AI 模型选择**：下拉或单选组，两个选项：`glm-4.6v-flash`（免费版，默认）/ `glm-4.6v`（正式版）。存 SettingsStore。
5. **「保存」按钮**：把页面上全部值写入 SettingsStore → Toast「已保存」。
6. 页面加载时：从 SettingsStore 读当前值回填。

### 注意

- 页面用"打开即读、保存才写"的模式（参考 Karma 的 draft 模式，见《时间设置-实现指南.md》第二节：局部状态编辑，点保存才落盘）。
- 存储目录选择后可顺带验证：目录下能否创建文件夹（可选，不强求）。

## 三、验收清单

- [ ] 新建页：选文件显示预览、可更换、可不选；名称空/非法字符时创建被拦截并提示
- [ ] 新建事项后：存储目录出现 `001-名称` 文件夹和 `.meta.json`；选了文件则文件已在文件夹内；返回主页列表出现该事项
- [ ] 连续新建两个事项编号为 001、002；删除一个后新建的编号复用最小未用（如删了 002 则新建为 002）
- [ ] 时间默认当前年月，可改为任意年月
- [ ] **AI 按钮处于禁用态**（本步不实现 AI）
- [ ] 设置页：选存储目录后重启应用授权仍在（能列出事项）
- [ ] 设置页：API Key 保存后重启仍在（加密存储）；模型选择可切换
- [ ] 设置页返回后主页面数据不受影响
