# v1.1 步骤 2 — 设置页可编辑 AI 识别提示词

## 一、目标

v1.0 的 AI 提示词硬编码在 `GlmApiClient.NAME_PROMPT`。v1.1 改为：设置页可编辑提示词（多行输入 + 实时计数 + 恢复默认按钮），AI 生成名称时使用用户自定义提示词；未设置/清空时自动回退默认（与 v1.0 行为完全一致）。

## 二、改动点（按依赖顺序实施）

### 1. `network/GlmApiClient.kt` — 提示词参数化

- 删除私有常量 `NAME_PROMPT`（默认值迁移至 `SettingsStore.DEFAULT_NAME_PROMPT`）
- `generateName()` 新增参数，带默认值 → 旧调用不破坏：

```kotlin
suspend fun generateName(
    context: Context,
    fileUri: Uri,
    apiKey: String,
    model: String,
    prompt: String = SettingsStore.DEFAULT_NAME_PROMPT,
): Result<String> = withContext(Dispatchers.IO) {
    try {
        val effectivePrompt = prompt.ifBlank { SettingsStore.DEFAULT_NAME_PROMPT } // 兜底
        ...
    }
}
```

- 四个私有函数各加 `prompt: String` 参数，函数体内 `systemMsg(NAME_PROMPT)` 改为 `systemMsg(prompt)`：
  - `generateFromImage`（图片 base64 vision）
  - `generateFromPdf`（PDF 文本提取路径）
  - `generateFromPdfViaVision`（PDF 文本不足时渲染首页 vision，由 generateFromPdf 透传）
  - `generateFromTxt`（TXT 文本路径）

### 2. `data/settings/SettingsStore.kt` — 存储键 + 默认常量单点来源

```kotlin
// ── AI 识别提示词（空/未设置 → 默认，默认值单点来源 DEFAULT_NAME_PROMPT） ──

fun getAiPrompt(): String {
    return prefs.getString(KEY_AI_PROMPT, null)?.takeIf { it.isNotBlank() }
        ?: DEFAULT_NAME_PROMPT
}

fun saveAiPrompt(prompt: String) {
    prefs.edit().putString(KEY_AI_PROMPT, prompt.trim()).apply() // trim 防纯空格
}

companion object {
    ...
    private const val KEY_AI_PROMPT = "ai_prompt"

    /** 默认 AI 提示词（v1.0 内置文案，逐字保留，勿改） */
    const val DEFAULT_NAME_PROMPT = """（v1.0 原文案，逐字保留）"""
}
```

> 依赖方向：`data/settings` 是底层，不反向依赖 `network`；默认常量归设置存储所有，`GlmApiClient` 引用它。

### 3. `ui/settings/SettingsViewModel.kt` — draft 模式扩展

沿用「打开即读、保存才写」：

```kotlin
private val _aiPrompt = MutableStateFlow("")
val aiPrompt: StateFlow<String> = _aiPrompt.asStateFlow()

fun load() { ...; _aiPrompt.value = settingsStore.getAiPrompt() }   // 追加
fun save() { ...; settingsStore.saveAiPrompt(_aiPrompt.value) }     // 追加
fun setAiPrompt(prompt: String) { _aiPrompt.value = prompt }

/** 恢复默认：只改草稿，需点保存才持久化（与 draft 模式一致） */
fun resetAiPrompt() { _aiPrompt.value = SettingsStore.DEFAULT_NAME_PROMPT }
```

### 4. `ui/settings/SettingsScreen.kt` — 多行输入框 + 恢复默认

文件顶部加常量 `private const val MAX_PROMPT_LEN = 2000`，收集 `val aiPrompt by viewModel.aiPrompt.collectAsState()`，在「AI 模型」区块之后、「保存」按钮之前插入：

> **注意**：新增提示词区块后内容会超屏，页面 Column 必须加 `.verticalScroll(rememberScrollState())` 并移除原 `Spacer(weight(1f))`（可滚动容器中 weight 失效），否则保存按钮会被挤出屏幕外无法查看（v1.1 实测踩坑）。

```kotlin
Divider()

// ── AI 识别提示词 ──
Text("AI 识别提示词", style = MaterialTheme.typography.labelLarge)
OutlinedTextField(
    value = aiPrompt,
    onValueChange = { viewModel.setAiPrompt(it.take(MAX_PROMPT_LEN)) },
    modifier = Modifier.fillMaxWidth(),
    label = { Text("提示词") },
    minLines = 5,
    maxLines = 10,
    supportingText = { Text("${aiPrompt.length}/$MAX_PROMPT_LEN，留空时使用默认提示词") },
)
Row(modifier = Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.End) {
    TextButton(onClick = { viewModel.resetAiPrompt() }) { Text("恢复默认") }
}
```

> 截断用 `take(2000)` 而非 `maxLength` 参数：Compose BOM 2024.04.01（material3 1.2.x）的 `OutlinedTextField` 无 maxLength 参数。

## 三、边界情况

| 场景 | 处理 |
|---|---|
| 用户清空保存 | 存 `""` → `getAiPrompt` 回退默认；`generateName` 内 `ifBlank` 二次兜底 |
| 只输入空格保存 | `saveAiPrompt` 里 `trim()` 后按空处理 |
| 超长输入（粘贴大段文本） | onValueChange `take(2000)` 硬截断 + supportingText 实时计数 |
| 恢复默认后不点保存就返回 | 草稿丢弃，下次进入重新 load()，与 API Key 行为一致 |
| 提示词含换行/引号 | putString 无限制；多行 TextField 天然支持；AI 侧由 system 消息承载 |
| 存量用户无感知 | 默认值逐字未变 + 默认参数 + getAiPrompt 回退，三保险 |
