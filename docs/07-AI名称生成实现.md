# 步骤 7：AI 名称生成实现（最后一步）

> 目标：接通智谱 GLM-4.6V——用户选中一个文件后，点「AI 生成」自动生成事项名称填入输入框。
> 前置：步骤 5 完成（新建页 AI 按钮占位、设置页 API Key/模型存储已就绪）。

## 一、网络层（`network/GlmApiClient.kt`）

### 基本信息

- 接口：`POST https://open.bigmodel.cn/api/paas/v4/chat/completions`
- Header：`Authorization: Bearer <api-key>`、`Content-Type: application/json`
- 请求体（OpenAI 兼容）：
  ```json
  {
    "model": "glm-4.6v-flash",
    "messages": [{
      "role": "user",
      "content": [ ... ]   // 按文件类型构造
    }]
  }
  ```
- 模型名从 SettingsStore 读取（默认 `glm-4.6v-flash`，设置页可切 `glm-4.6v`）。
- 用 OkHttp；超时设置 30 秒（`OkHttpClient` 的 readTimeout）；在 IO 线程执行。

### 按文件类型构造 content（三类，均不需公网托管）

| 类型 | 构造方式 |
|---|---|
| **图片**（jpg/jpeg/png/gif/bmp/webp） | 读文件二进制 → base64 → `{"type":"image_url","image_url":{"url":"data:image/<mime>;base64,<data>"}}` + 提示词文本。**单图 ≤5MB**：超过先压缩（BitmapFactory 解码 + 等比压缩，质量/尺寸降到 <5MB，注意 `BitmapFactory.Options.inSampleSize`，内存吃紧时先采样再压缩） |
| **txt**（含 md） | 本地读出文本 → 直接作为 `{"type":"text","text":"文件内容：\n<内容>\n\n<提示词>"}`。内容过长（>3 万字符）截断尾部 |
| **pdf** | 两步：① `POST https://open.bigmodel.cn/api/paas/v4/files`（multipart/form-data：`file` = 文件二进制、`purpose = "file-extract"`）→ 响应取 `id`；② `GET https://open.bigmodel.cn/api/paas/v4/files/{id}/content` → 抽取的文本（byte 流）→ 按 txt 方式发文本消息。**文件 >50MB 拒绝**并提示"文件过大" |
| 其他格式 | 不支持 → 返回错误"暂不支持该文件类型" |

- **重要**：`file_url` 不支持 base64（仅 `image_url` 支持），所以 pdf 走"上传→抽取"而不是直接传文件；一次请求只传一种模态。

### 提示词

```
你是文件命名助手。请根据下面文件的名称和内容，为它所在的事项生成一个简洁的中文名称：
- 要求：不超过 20 个字；概括内容核心（如"房租转账"、"6月工资流水"）；
- 直接输出名称本身，不要解释、不要引号、不要加"建议名称："等前缀。
```

### 响应解析与清洗

- 解析 `choices[0].message.content`；
- 清洗：去首尾空白、去掉可能的引号（`"` `'` `「」`）、若返回多行取第一行；
- 超长截断到 20 字；
- 失败/超时/非 200 → 抛带中文信息的异常（区分：key 无效 401/403、网络错误、模型繁忙 429、余额不足）。

## 二、新建页接通（`ui/create/`）

1. **启用条件**（不满足则按钮禁用）：
   - 已选择文件（未选 → 禁用，点击提示「请先选择文件」）；
   - 已配置 API Key（未配置 → 禁用，点击提示「请先到设置页配置 API Key」）。
2. **点击流程**：按钮进入「生成中…」转圈禁用态 → 按文件类型调 GlmApiClient → 成功：结果填入名称输入框（用户可继续手动修改）→ 失败：Toast 错误信息 → 恢复可点状态。
3. 生成前判断文件类型走对应分支（FileType 工具，见步骤 2）。

## 三、验收清单

- [ ] 未选文件 / 未配 Key 时按钮禁用，点击有对应提示
- [ ] 设置页配置 Key（可先用智谱免费额度或 flash 免费版）后，选图片 → 点 AI 生成 → 名称自动填入且合理（如发票截图 → "发票"类名称）
- [ ] 选 txt → 生成成功（内容被理解）
- [ ] 选 pdf → 生成成功（走文件抽取）
- [ ] 生成的名称可继续手动修改
- [ ] 断网 / 错误 Key → Toast 中文错误提示，按钮恢复可用，不崩溃
- [ ] 生成过程中按钮显示转圈，不可重复点击
- [ ] 图片超过 5MB 时自动压缩后仍能成功
- [ ] 最终用户手动输入名称的路径（不用 AI）不受影响
