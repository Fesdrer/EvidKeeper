# EvidKeeper — 证据保存助手

安卓应用，用于保存交易截图、回执、发票、合同、证件等重要文件。以「事项」为单位组织文件，支持 AI 自动命名。

## 功能

- **事项管理**：创建、改名、删除事项，设置星标（重要事项置顶）
- **文件存储**：每个事项一个文件夹，支持图片、PDF、TXT 等格式
- **文件预览**：网格展示，图片显示缩略图，PDF/TXT 显示类型图标，点击用系统查看器打开
- **AI 命名**：选文件后一键生成事项名称（基于智谱 GLM-4.6V 多模态模型，看图理解内容）
- **搜索**：按事项名称或文件名实时过滤
- **回收站**：删除的文件和事项移入 `remove/` 目录，可手动恢复
- **数据自主**：所有文件保存在你指定的手机文件夹中，无云端依赖

## 技术栈

| 层 | 技术 |
|---|---|
| UI | Jetpack Compose + Material3 |
| 导航 | Navigation Compose |
| 架构 | ViewModel + StateFlow |
| 存储 | SAF（DocumentFile）+ EncryptedSharedPreferences |
| 网络 | OkHttp |
| 图片 | Coil |
| 序列化 | kotlinx-serialization |
| AI | 智谱 GLM-4.6V API |
| 最低 SDK | Android 8.0（API 26） |

## 使用指南

### 1. 首次设置

1. 打开应用，点击右上角 **齿轮图标** 进入设置
2. 点击 **存储文件夹** → 选择一个目录（如 `文档/EvidKeeper`）
3. （如需 AI 功能）输入 **智谱 API Key**（在 [open.bigmodel.cn](https://open.bigmodel.cn) 注册获取）
4. 选择 AI 模型：`glm-4.6v-flash`（免费）或 `glm-4.6v`（付费，效果更好）
5. 点击 **保存**

### 2. 新建事项

1. 主页点击 **+** 进入新建页
2. （可选）点击 **添加文件** 选一个文件
3. 手动输入名称，或选了文件后点 **AI 生成** 自动命名
4. 点击时间可修改年月（默认当前）
5. 点击 **创建**

> **AI 生成按钮启用条件**：已选文件 + 已在设置页配置 API Key。不满足时按钮为灰色禁用态。

### 3. 管理事项

- **点击事项** → 进入详情页，查看/添加文件
- **长按事项** → 弹出菜单：改名 / 删除
- **星标**：详情页点击星标图标切换重要/普通，主页重要事项自动置顶
- **搜索**：主页顶部搜索框输入关键词，按名称或文件名实时过滤

### 4. 详情页操作

- **添加文件**：底部 **+ 添加文件** 按钮
- **查看文件**：点击文件用系统查看器打开
- **长按文件**：改名（保留扩展名）/ 删除（移入回收站）
- **改名**：点击顶部事项名称
- **改时间**：点击时间，年月滚动选择器
- **星标**：点击星标切换

### 5. 存储结构

```
你选择的目录/
├── 001-房租/
│   ├── meta.json          ← 事项元数据（名称、时间、星标）
│   ├── 合同.pdf
│   └── 转账截图.jpg
├── 002-电费账单/
│   ├── meta.json
│   └── 7月账单.pdf
├── 003-录取通知书/
│   └── meta.json
└── remove/                ← 回收站（删除后移入此处）
    └── 001-房租/
```

### 6. 恢复已删除内容

用系统文件管理器打开存储目录，进入 `remove/` 文件夹，把需要的文件/文件夹移回上级目录即可。应用会在下次扫描时重新识别。

### 7. 排序规则

重要事项置顶 → 组内按时间从新到旧 → 同年月按编号从大到小

### 8. AI 命名原理

| 文件类型 | 处理方式 |
|---------|---------|
| 图片（JPG/PNG 等） | 直接发送给视觉模型识别内容 |
| PDF（文本型） | 上传提取文字 → 发送给模型 |
| PDF（扫描件/图片型） | 渲染首页为图片 → 发送给视觉模型 |
| TXT | 读取文字内容 → 发送给模型 |

## 构建

```bash
# 克隆项目后用 Android Studio 打开，或命令行：
./gradlew assembleDebug
```

需要在 `local.properties` 中配置 Android SDK 路径。

## 依赖

- 智谱 AI API（AI 命名功能需要）
- Android 8.0+
- 存储权限（通过 SAF 授权，无需 MANAGE_EXTERNAL_STORAGE）
